    git clone https://github.com/myrakrusemark/rankmark
cd rankmark && uv venv .venv --python 3.12 && source .venv/bin/activate && uv pip install -e ".[web]"
rankmark serve --model Qwen/Qwen3-14B

    Then open http://localhost:8770. The README covers which models and devices work, and why a text written on a GPU will not read on a CPU.

    How this works

    Every word is a ranked choice

    A language model does not write words. At each step it scores every token it knows, about 150,000 of them for the models here, and something picks one. Usually the pick is the top score, or a sample from the top few. Hover any word the tool wrote and you see where that word sat in the ranking.

    Where a bit can hide

    When the top score is far ahead of the rest there is no room: taking the second choice would read as a mistake. When two or three candidates score about the same, the choice is free, and a free choice can carry a bit. Rankmark measures that freedom as the entropy of the model's scores and only plants bits above a gate. The gate is set per model, because a bigger model is surer of itself and offers fewer free choices.

    One bit, one choice

    At a free choice the writer takes the first-ranked word for a 0 and the second-ranked word for a 1, and that is the whole channel. No hidden characters and no changed spelling: the words are the message, and the text reads as the model's own writing because it is.

    The frame

    Bits alone are noise, so Rankmark wraps your tag in a frame. It opens with the knock, a fixed pattern of bits a reader can find anywhere in the text. Then comes a label with the tag's length and a 3-bit fingerprint of the model, then your tag, then a checksum that seals it. The standard and heavy settings add repair data that corrects bits an edit damaged. The strip beside the tool is that frame, one cell per bit.

    Reading

    The reader feeds the text back through the same model one word at a time and asks, at each word, where that word sat in the ranking. Above the gate, first place means 0 and second place means 1. Those bits go into the strip until the knock, the label and the checksum line up, and the checksum decides.

    The model is the key

    Deployed watermarks use a secret key, a number that decides which words count as 0 and which as 1, and only the key holder can check. Rankmark has no secret: the ranking itself is the key, and only the model that wrote the text reproduces it. A different model, even a close sibling of the writer, ranks the near-tie words differently often enough that the checksum fails. Reading is an attribution test among open models. It also means anyone with the same weights can forge a mark.

    Breaking it

    Each word was ranked against everything before it, so cutting the start changes every later ranking and the frame dies. Cutting the end leaves the frame intact when it was planted early enough. Swapping words breaks the bits at the swap, and the repair data in the standard and heavy settings absorbs a few of those. Paraphrasing rewrites every ranking and kills the frame outright. The break-it buttons do each of these so you can watch.

    How the labs do it

    Anthropic began watermarking Claude's text in August 2026 with a version of Google DeepMind's SynthID-Text. Google has used SynthID-Text in Gemini since 2024. OpenAI had built a text watermark by 2024 and, as of September 2026, has not shipped it. All of these are keyed: the pattern comes from a secret, the vendor holds the secret, and the detector answers one question, how likely it is that this model was involved.

    "AI detectors" that guess from writing style are a different product. They have no key and no frame, they are guessing, and a 2023 Stanford study found them flagging most essays by non-native English writers as machine-written. A watermark is a fact planted at writing time; a detector is a bet.

    What this is and is not

    A research demo. Read every verdict with these in mind:
    • A validating frame means "a frame planted with this model validates here." It does not mean this model wrote the rest of the text.
    • No frame proves nothing. Unmarked, edited, wrong model, or a different engine build all look the same.
    • Rankmark cannot detect text from ChatGPT, Claude or Gemini, and no public tool reads their watermarks.
    • The mark is visible to anyone who ranks the words with the same model, dies under paraphrase, and can be forged by anyone with the weights.
    • Reading on another machine works because the engine is bit-exact across the browsers and processors we test on every change; the list is in the repository.
    Rankmark is a research demo by Myra Krusemark. Code and tests Models: Qwen3, Alibaba, Apache 2.0. Engine: llama.cpp compiled to WebAssembly.

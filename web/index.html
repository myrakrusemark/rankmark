The watermark you can't see

A watermark lives in the words a language model chooses. Here's how it works, and a tool for rolling your own.

← HomeSkip to the tool

Every token is a choice

At every step, a model scores the possible next tokens, then picks one from the list. Try it out below: lower temperature favors the leaders; higher temperature spreads the chances more evenly.

    Hidden in plain sight

    Whenever several next words would work, watermarking can steer the choice to leave a pattern. A detector uses the same key to check for that pattern.

    You can do this yourself

    This demo runs Qwen3 in your browser and hides your message in its choices: at eligible steps, odd ranks carry 0 and even ranks carry 1. Write an opening, choose a message, and watch the bits fall into place.

    What survives an edit?

    Change the text and see which bits still match the original, which flip, and which disappear. This compares against your saved run; the percentage is agreement among surviving aligned bits, not a probability of authorship.

    Reading with different models

    Different models rank words differently, so they can recover different bits from the same passage. These measured examples compare known writers and readers; they do not identify the author of an unknown text.

    Give the choices a secret

    A secret key changes which words the writer favors; a reader with the same key knows which pattern to look for. Try matching passphrases, then change only the reader’s.

    Sources and privacy

    Anthropic announced watermarking for new Claude models in August 2026, with older models to follow; Gemini has used SynthID-Text since 2024. Read Anthropic’s explanation, the SynthID-Text paper, and the EU marking guidance.

    The key stays with the provider; it is not a message hidden in the text. Watermarks can carry identifiers by design, but Anthropic says its mark does not identify users or conversations.

    Run the Python code directly to write and read marked text on your machine. Github Repo

    Install

    git clone https://github.com/myrakrusemark/rankmark
cd rankmark
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e .

    Run this page locally

    With Node.js installed, run this from the cloned rankmark folder:

    node web/serve.mjs

    Open http://127.0.0.1:8770/. The models run in your browser, including passphrase keying. Keep the terminal open; press Ctrl+C to stop the server. The Python installation is only needed for the commands below.

    Write

    rankmark --profile 0 --temperature 0.7 embed \
  --model Qwen/Qwen3-0.6B \
  --prompt "It was late in the harbor when the last boat came in, and" \
  --payload a7 --max-tokens 800 --verify > marked.txt

    a7 is a one-byte example payload in hexadecimal. The first run downloads the model; --verify checks that the result reads back.

    Read

    rankmark --profile 0 decode \
  --model Qwen/Qwen3-0.6B --file marked.txt

    Use the same model, device and settings for writing and reading. This Python version is unkeyed and is a separate setup from the browser engine.

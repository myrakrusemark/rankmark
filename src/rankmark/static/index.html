Type a secret. The AI writes an innocent-looking paragraph and hides your message in its word choices — invisible to anyone reading, but the same AI can find it again later. Takes a few minutes (it thinks one word at a time).

Generates token by token, picking rank-0 or rank-1 tokens so their parity spells out the payload. Underlined tokens carry a bit; the rest are carrier-nulls. Set a window (e.g. 64) to make the mark survive truncation — ranks are then scored from bounded context, so cutting the head off the text only disturbs the first window tokens instead of everything. CPU speed: expect a couple of tokens per second (slower with a window).

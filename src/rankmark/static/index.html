Generates token by token; each bit is the parity of the chosen token's rank. The secret message fills the payload hex automatically; edit the hex for raw bytes. Temperature 0 is greedy (rank 0/1 only — cleanest signal, but small models can fall into repetition loops); above 0 it samples among same-parity tokens, which breaks the loops and looks like ordinary text — the decode is identical either way. Set a window (e.g. 64) to survive truncation. With this panel closed, all of these are chosen automatically.
